# Учебный конспект и портфолио кейсов SOC L1

Репозиторий с практическими расследованиями журналов безопасности Windows и Linux, анализом сетевого трафика, проверкой индикаторов компрометации (IoC) и алгоритмами реагирования на инциденты (Triage).

## Содержание

### Расследования Windows и SIEM (`windows/`)
- **[Кейс №1: Ночной брутфорс RDP и скрытый запуск PowerShell](./windows/case-01.md)** — анализ Event ID `4625`, `4624`, `4688` и сетевого соединения C2.
- **[Кейс №2: Рабочая смена в SIEM (3 инцидента)](./windows/case-02.md)** — фишинг с запароленным архивом (`True Positive`), плановые работы админа по SMB (`False Positive`) и блокировка перебора RDP.

### Расследования Linux (`linux/`)
- **[Кейс №3: Взлом сервера БД и создание бэкдор-пользователя](./linux/case-03.md)** — анализ `/var/log/auth.log` и команды `useradd`.
- **[Кейс №4: Отделение работы админа от ночной атаки SSH](./linux/case-04.md)** — перебор паролей (`invalid user`), выдача прав на выполнение скрипта (`chmod +x`).
- **[Кейс №5: Брутфорс SSH, запуск `.sh`-скрипта и создание бэкдора](./linux/case-05.md)** — полная цепочка компрометации сервера резервного копирования.
