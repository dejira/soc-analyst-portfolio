# Портфолио учебных расследований SOC Analyst (L1)

Этот репозиторий содержит практические разборы инцидентов информационной безопасности (учебные кейсы и симуляции смены дежурного аналитика первой линии SOC).

## Ключевые навыки и инструменты
* **Сети и протоколы:** модель TCP/IP, определение внутренних и внешних IP-адресов, анализ сетевых соединений (`netstat`), знание базовых портов (`22`, `53`, `80`, `443`, `445`, `3389`).
* **Анализ журналов Windows:** работа в Event Viewer, разбор ключевых событий безопасности (`4624` — успешный вход, `4625` — ошибка входа, `4688` — создание процесса), выявление аномальных связок процессов и скрытых команд PowerShell (`-w hidden`, `-enc`).
* **Анализ фишинга:** выявление подмены доменов (тайпосквоттинг), проверка вложений с двойными расширениями и запароленных архивов.
* **Триаж в SIEM:** классификация срабатываний на **True Positive** и **False Positive**, работа по плейбукам, принятие мер по первичному сдерживанию (изоляция хоста, блокировка IP/учётных записей, эскалация на L2).
* **Threat Intelligence:** проверка индикаторов компрометации (IP-адреса, домены, хеш-суммы SHA-256 через `certutil`) на порталах **Kaspersky OpenTIP**, **VirusTotal** и **AbuseIPDB**.

# Кейс №02: Массовый подбор паролей по протоколу RDP (Brute-force)

## 1. Вводные данные и суть тревоги
* **Объект:** Сервер удалённого доступа компании (`10.50.5.5`).
* **Источник активности:** Внешний IP-адрес `193.32.162.88`.
* **Целевой порт:** `3389` (RDP — Remote Desktop Protocol).
* **Срабатывание в SIEM:** Зафиксировано 210 неудачных попыток входа за 3 минуты с одного внешнего IP-адреса.

## 2. Ход анализа (хронология событий)
* **Анализ сетевого направления:** Источник подключения (`193.32.162.88`) является публичным внешним IP-адресом. Подключение направлено на порт `3389`, который отвечает за удалённый рабочий стол Windows и часто используется для первичного проникновения в инфраструктуру.
* **Анализ журнала безопасности Windows:**
  * Зафиксировано **210 событий с кодом `4625`** (неудачная попытка входа) за 3 минуты, что явно указывает на автоматизированный перебор паролей (атаку методом *Brute-force*).
  * События с кодом **`4624`** (успешный вход в систему) за этот период **отсутствуют** — злоумышленнику не удалось подобрать действующий пароль.
* **Разведка угроз (Threat Intelligence):** Проверка адреса `193.32.162.88` через базу *AbuseIPDB* показала рейтинг жалоб **100%** (известный источник массового сканирования и подбора паролей по всему миру).

## 3. Вердикт и меры реагирования
* **Классификация:** **True Positive** (подтверждённая попытка внешней атаки; атака успешно отражена).
* **Выполненные действия (L1):**
  1. Внешний IP-адрес `193.32.162.88` добавлен в список блокировки на периметровом межсетевом экране (файрволе).
  2. Проверено отсутствие успешных сессий (`4624`) с данного адреса на других серверах компании.
  3. Сформирована рекомендация для системных администраторов: закрыть прямой доступ.
