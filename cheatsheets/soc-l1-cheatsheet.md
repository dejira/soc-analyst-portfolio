# Шпаргалка дежурного аналитика SOC L1

## 1. Внутренние («серые») IP-адреса
Внутренними считаются **только** эти три диапазона (все остальные — внешние в интернете):
- `10.0.0.0` – `10.255.255.255` (начинаются на `10.`)
- `172.16.0.0` – `172.31.255.255` (начинаются на `172.`, второе число от `16` до `31`)
- `192.168.0.0` – `192.168.255.255` (начинаются на `192.168.`)

## 2. Базовые сетевые порты
- **22 (SSH)** — защищённое удалённое управление серверами (обычно Linux).
- **53 (DNS)** — перевод доменных имён в IP-адреса.
- **80 (HTTP)** — обычный веб-трафик без шифрования.
- **443 (HTTPS)** — защищённый веб-трафик (сайты с замочком).
- **445 (SMB)** — сетевые папки и обмен файлами в Windows.
- **3389 (RDP)** — удалённый рабочий стол Windows.

## 3. Главные коды событий Windows (Журнал «Безопасность»)
- **4624** — успешный вход в систему.
- **4625** — неудачная попытка входа (много событий подряд = брутфорс).
- **4688** — создание нового процесса (запуск программы).
  - *Опасные признаки:* запуск `powershell.exe` или `cmd.exe` из Office/почты, флаги `-w hidden` (скрытое окно) и `-enc` (зашифрованная команда).

## 4. Журналы и команды Linux
- **`/var/log/auth.log`** — журнал входов по SSH и команд администратора (`sudo`).
- **`Failed password` / `invalid user`** — неудачный вход или перебор несуществующих логинов.
- **`Accepted password`** — успешный вход в систему.
- **`chmod +x file.sh`** — выдача файлу права на запуск (подготовка).
- **`./file.sh` или `bash file.sh`** — непосредственный запуск скрипта.
- **Полезные команды:**
  - `grep "Failed password" /var/log/auth.log` — найти все ошибки входа.
  - `grep "sudo" /var/log/auth.log` — найти все действия с правами администратора.
  - `tail -n 20 /var/log/auth.log` — посмотреть последние 20 строк лога.

## 5. Проверка индикаторов компрометации (IoC)
- **Kaspersky OpenTIP** (`://kaspersky.com`) — проверка IP, доменов, ссылок и хешей.
- **VirusTotal** (`virustotal.com`) — проверка по 70+ антивирусам (загружать только **хеш-сумму**, не сами рабочие документы!).
- **Расчёт хеша SHA-256 в Windows:** `certutil -hashfile путь_к_файлу SHA256`



## 6. Основные коды для расследований

| Logon Type | Название | Что означает | На что обращает внимание SOC L1 |
| :--- | :--- | :--- | :--- |
| **2** | Interactive | Локальный вход за клавиатурой и монитором ПК | Подозрительно, если происходит ночью в пустом офисе |
| **3** | Network | Сетевой вход (SMB, общие папки, WMI, PsExec) | Основной признак перемещения злоумышленника внутри сети (Lateral Movement) |
| **4** | Batch | Запуск запланированной задачи (Scheduled Task) | Проверка легитимности скриптов в планировщике |
| **5** | Service | Запуск фоновой системной службы Windows | Создание вредоносных служб для закрепления (Persistence) |
| **7** | Unlock | Разблокировка экрана после возвращения за ПК | Обычная активность, но серия ошибок `4625` с типом `7` — попытка подбора пароля физически |
| **10** | RemoteInteractive | Удалённый рабочий стол (RDP, стандартный порт 3389) | Главный вектор внешнего брутфорса, если порт открыт в интернет |
