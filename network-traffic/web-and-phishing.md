# 🛡️ Веб-атаки, коды HTTP и Фишинг (Шпаргалка Junior SOC)

## 1. Главные веб-атаки в логах (`access.log`)

* **SQL-инъекция (SQLi):** внедрение команд к базе данных через поля ввода или URL.
  * *Улики в логах:* `UNION SELECT`, `' OR 1=1--`, `SLEEP(5)`, `INFORMATION_SCHEMA`.
* **XSS (Межсайтовый скриптинг):** внедрение вредоносного JavaScript-кода на страницу сайта.
  * *Улики в логах:* `<script>`, `alert(1)`, `onerror=`, `document.cookie`.
* **Path Traversal / LFI (Обход каталогов):** попытка выйти за пределы папки сайта и прочитать системные файлы сервера.
  * *Улики в логах:* `../../../../etc/passwd` или `..\..\windows\win.ini`.

---

## 2. Коды ответа HTTP-сервера (Сработала атака или нет?)

| Код | Название | Значение для SOC-аналитика при атаке |
| :--- | :--- | :--- |
| **`200`** | OK | **Критично (Успех атаки):** сервер принял вредоносный запрос и отдал данные хакеру. |
| **`401`** | Unauthorized | Перебор паролей к форме входа на сайте (Brute Force). |
| **`403`** | Forbidden | Атака заблокирована веб-сервером или WAF (True Positive, но без взлома). |
| **`404`** | Not Found | Массовое сканирование сайта и поиск скрытых файлов/папок (фаззинг). |
| **`500`** | Internal Server Error | Внутренний сбой сервера (часто бывает при подборе SQL-инъекции). |

## 3. Признаки фишинговых писем

1. **Несовпадение отправителя:** в поле `From` указано известное имя («Налоговая», «Сбербанк»), а реальный домен в `Return-Path` или после `@` — поддельный или бесплатный (`tax-info99.xyz`).
2. **Тайпсквоттинг (подмена букв):** визуально похожий адрес сайта (`rnicrosoft.com` вместо `microsoft.com` или `sberbаnk.ru` с латинской буквой).
3. **Запароленный архив с паролем в теле письма:** главный технический трюк для **обхода почтового антивируса и песочницы (Sandbox)** — сканер не может открыть архив без пароля и пропускает вирус к пользователю.
4. **Опасные вложения:** файлы `.exe`, `.scr`, `.vbs`, `.js`, `.iso` или офисные документы с макросами (`.docm`, `.xlsm`).
